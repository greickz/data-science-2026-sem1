## Descrição

Este repositório é uma compilação abrangente de exercícios práticos desenvolvidos durante o primeiro semestre do curso de Ciência de Dados em 2026. Os exercícios abordam uma variedade de tópicos fundamentais, desde estruturas de dados básicas em Python até técnicas avançadas de raspagem de dados web e tratamento de dados não estruturados.

## Tecnologias Utilizadas

- **Python 3.x**: Linguagem principal para todos os scripts e análises.
- **Pandas**: Para manipulação e análise de dados estruturados.
- **NumPy**: Para operações numéricas e arrays.
- **Matplotlib e Seaborn**: Para visualização de dados e gráficos.
- **Selenium**: Para raspagem de dados dinâmicos em sites web.
- **BeautifulSoup e Requests**: Para raspagem de dados estáticos e requisições HTTP.
- **Jupyter Notebook**: Para análises interativas e documentação de processos.

## Estrutura do Projeto

O repositório está organizado em pastas temáticas, cada uma correspondendo a um módulo ou conjunto de exercícios do curso:

- **Artigos/**: Contém artigos relacionados a extensão universitária e projetos integradores, incluindo discussões sobre temas avançados em ciência de dados.
- **Estrutura_de_Dados/**: Exercícios sobre criação e leitura de dados estruturados, semi-estruturados e não estruturados. Inclui arquivos de exemplo como `dados_nao_estruturados.csv` e `dadosSemi.json`.
  - `aula/`: Scripts para criação e leitura de dados (e.g., `criacao_estruturado.py`).
  - `exercicios/`: Práticas com listas, dicionários, tuplas e estruturas heterogêneas.
- **Exercicios_Estruturas_Condicionais_de_Lista/**: Exercícios com compreensões de lista e estruturas condicionais.
- **Exercicios_For/**: Loops e iterações com `for`, incluindo datas específicas como 18-02.
- **Exercicios_Funcoes/**: Desenvolvimento de funções em Python, com listas de exercícios e uma calculadora de teste.
- **Exercicios_If/**: Estruturas condicionais básicas.
- **Exercicios_Lista_e_Tuplas/**: Manipulação de listas e tuplas, com exemplos e exercícios práticos.
- **Exercicios_Operadores/**: Uso de operadores aritméticos, lógicos e de comparação.
- **Exercicios_Raspagem/**: Raspagem de dados web, incluindo scripts para sites como Kabum e análises em notebooks (e.g., `raspagem_kabum_consoles.py`, `tratamento.ipynb`).
- **Exercicios_Tratamentos/**: Tratamento e limpeza de dados, com notebooks para análise.
- **Exercicios_While/**: Loops com `while`, organizados por datas.
- **Licoes_Faculdade/**: Lições e anotações do curso, incluindo atalhos e comandos Python.

## Dados

Os dados utilizados nos exercícios incluem:
- **Dados de Exemplo**: Arquivos como `dados_nao_estruturados.csv` (dados CSV com nome, idade e cidade) e `dadosSemi.json` (dados semi-estruturados), criados para praticar manipulação.
- **Dados Raspados**: Extraídos de sites como Kabum (consoles) e imóveis, utilizando Selenium e BeautifulSoup. Esses dados incluem preços, títulos e outras informações de produtos.

Os dados são fictícios ou públicos, focados em aprendizado e não em aplicações comerciais.

## Resultados / Insights

Através dos exercícios, foram desenvolvidas habilidades em:
- Manipulação de estruturas de dados complexas, resultando em scripts eficientes para leitura e escrita de dados.
- Raspagem web, coletando dados de e-commerce e gerando DataFrames com Pandas para análise.
- Análises exploratórias em notebooks, revelando padrões como distribuições de preços e tendências em dados de produtos.
- Construção de funções reutilizáveis e algoritmos lógicos, aplicados em calculadoras e processamentos de listas.

Esses insights demonstram a capacidade de transformar dados brutos em informações acionáveis, um pilar da ciência de dados.
